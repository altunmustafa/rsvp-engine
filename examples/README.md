# Examples

These examples demonstrate how applications use RSVP Engine packages while owning input handling, rendering, and UI.

- [Core browser reader](core-browser-reader/README.md): framework-free text playback with browser controls, speed adjustment, and optimal viewing position alignment
- [Core Readability reader](core-readability-reader/README.md): extract article text from HTML with Mozilla Readability and pass it to Core for playback
- [Core terminal reader](core-terminal-reader/README.md): word-by-word playback and optimal viewing position alignment in a Node.js terminal
- [React reader](react-reader/README.md): playback controls and selective state reads through React context hooks

Each example's README includes commands to run it from the repository root. For workspace setup and development checks, see the [contributor guide](../CONTRIBUTING.md).
